3. 功能说明
-----------
现在系统完全依赖后端API：
- 登录：通过 /auth/login 验证用户，获取token
- 用户管理：/users 接口（分页、增删改查）
- 角色管理：/roles 接口（分页、增删改查）
- 权限管理：/permissions 接口（分页、增删改查）
- 菜单管理：/menus 接口（分页、增删改查）

所有分页都通过后端进行（MyBatis-Plus分页插件），每页10条记录。

4. 使用说明
-----------
1. 确保后端服务正常运行在 http://localhost:8080
2. 确保数据库已初始化，包含菜单、用户等数据
3. 使用有效的账号登录（默认 admin / 123456）
4. 登录成功后可以使用完整的系统管理功能

5. 重要提示
-----------
- 后续所有修复和新增功能都必须直接对接后端API
- 绝对不再使用模拟数据作为解决方案
- 任何前端功能都需要有对应的后端API支持
- 登录必须获取有效的JWT token才能访问受保护的资源
