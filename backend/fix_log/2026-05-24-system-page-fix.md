# 修复日期：2026-05-24 00:45 (CST)

## 问题描述

点击"系统管理"导航项时没有任何反应，页面没有切换。

## 问题原因

CSS样式中有冲突的规则，导致页面显示状态管理混乱。原CSS有以下问题：
1. `.page-graph` 默认是 `display: flex`，可能导致active类切换失效
2. 有重复冲突的样式规则

## 修复内容

### 修改文件
- `frontend/views/main/main.css`

### 修改要点

1. **修改 `.page-graph` 样式**
   - 改为默认 `display: none`
   - 只有添加了 `active` 类时才是 `display: flex`

2. **简化 CSS 规则**
   - 去除重复冲突的样式定义
   - 确保两个页面默认都是隐藏的，只有active类激活才显示

## 相关文件：
- `frontend/views/main/main.js` (已优化页面切换逻辑)

## 验证步骤

1. 刷新浏览器页面
2. 点击顶部导航的"系统管理"
3. 应该能看到系统管理页面，包含用户管理、角色管理等标签页
4. 再点击"知识图谱"应该能切换回来
